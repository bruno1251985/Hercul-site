# Hercul — public website

Public landing-page repository for Hercul, maintained by [Bruno Aguiar](https://github.com/bruno1251985).

**Website:** [hercul.pt](https://hercul.pt)

## Scope

This repository contains the public website artifact. The Hercul application and its ongoing rebuild are maintained separately in private repositories.

| File | Purpose |
| --- | --- |
| `index.html` | HTML website artifact |
| `README.md` | Project overview and review guide |

## Review guide

- Inspect the public HTML artifact to review the website implementation.
- Visit the website to see the current Hercul experience. The live website may evolve independently of this repository.
- See [my profile](https://github.com/bruno1251985) for the broader portfolio and project summaries.

## Run locally

Download or clone this public repository and open `index.html` in a browser. For a local HTTP preview, run `python3 -m http.server 8000` from the repository directory and open `http://localhost:8000`.

## Project notes

This is a small HTML repository with a single website artifact. It does not include the application's backend or private application source. No automated test suite is included. Accessibility, performance and production readiness require separate evaluation; no benchmark claims are made here.
